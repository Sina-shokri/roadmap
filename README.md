# 🗺️ نقشه راه جامع و اختصاصی برنامه‌نویسی بک‌اند (Java & Spring Boot)
### مسیر موازی دومحوره (Dual-Track Backend Mastery) به زبان فارسی

به این مخزن خوش آمدید! این ریپازیتوری یک راهنمای عملی، گام‌به‌گام و جامع برای تبدیل شدن به یک **مهندس ارشد بک‌اند با زبان جاوا (Java) و فریم‌ورک اسپرینگ‌بوت (Spring Boot)** است.

هدف این نقشه راه این است که مهارت‌ها به صورت **موازی (Parallel)** پیش بروند؛ یعنی یادگیری فریم‌ورک و کدهای دنیای واقعی همگام با مفاهیم پایه‌ای علوم کامپیوتر، دیتابیس (SQL) و طراحی سیستم (System Design) شکل بگیرد تا فرآیند یادگیری خسته‌کننده نباشد و دانشجو از همان ابتدا طعم ساخت نرم‌افزار را بچشد.

## 📊 داشبورد پیگیری پیشرفت کلی (Progress Tracker)

دوست شما می‌تواند با ویرایش این فایل یا تیک زدن چک‌باکس‌ها در گیت‌هاب، میزان پیشرفت خود را لحظه‌به‌لحظه ارزیابی کند:

### 🚀 لاین A: مهندسی کاربردی جاوا و اسپرینگ
- [ ] فاز ۱: تسلط بر Java 21 (شیءگرایی عمیق، Records، Pattern Matching و Exception Handling)
- [ ] فاز ۲: تسلط بر Collections Framework، Lambdas و Streams API
- [ ] فاز ۳: ورود به Spring Boot 3 (مفاهیم IoC/DI، ساخت REST Controllerها، اعتبارسنجی)
- [ ] فاز ۴: اتصال به دیتابیس با Spring Data JPA و حل چالش‌های ORM
- [ ] فاز ۵: راه‌اندازی Spring Security 6 و احراز هویت با JWT
- [ ] فاز ۶: تست‌نویسی جامع (JUnit 5, Mockito) و کانتینرسازی با Docker

### 🧠 لاین B: علوم کامپیوتر، SQL و طراحی سیستم
- [ ] فاز ۱: تحلیل زمانی و فضایی با Big-O و فهم حافظه JVM (Stack vs Heap)
- [ ] فاز ۲: تحلیل داخلی ساختمان‌داده‌ها (به‌ویژه نحوه کار HashMap، تصادم‌ها و درخت‌های قرمز-سیاه)
- [ ] فاز ۳: تسلط بر پترن‌های الگوریتمی (Two Pointers, Sliding Window, Fast/Slow Pointers, Binary Search)
- [ ] فاز ۴: تسلط عمیق بر SQL خام (Joins, Aggregations, Window Functions, Indexing B-Trees, ACID)
- [ ] فاز ۵: چندنخی، شرایط رقابتی (Race Conditions)، قفل‌ها و Virtual Threads
- [ ] فاز ۶: اصول طراحی سیستم (Caching با Redis، لود بالانسر، Message Broker با Kafka، مقیاس‌پذیری)

### 🛠️ پروژه‌های عملی
- [ ] پروژه ۱: Java Core Performance Benchmarker
- [ ] پروژه ۲: Task Manager REST API (Spring Boot + Postgres)
- [ ] پروژه ۳: E-Commerce Platform (Auth + Redis Cache + Payment Flow)
- [ ] پروژه ۴: Event-Driven Order Processing System (Kafka + Docker)

## 💡 قوانین طلایی برای موفقیت در این مسیر

1. **کدنویسی روزانه و واقعی:** صرفاً تماشای ویدیو یا مطالعه متن کافی نیست. هر مفهوم باید مستقیماً با نوشتن کد در IntelliJ IDEA تست و اجرا شود.
2. **ارتباط دادن تئوری به عمل:** هر زمان که در Track B مفهومی مثل B-Tree یا Hash Map مطالعه شد، فوراً بررسی شود که دیتابیس PostgreSQL یا کالکشن `HashMap` جاوا چگونه از آن استفاده می‌کند.
3. **توجه به جزئیات پرفورمنس:** یک جونیور فقط کدی می‌زند که کار کند؛ یک مهندس واقعی به پیچیدگی زمانی، مصرف حافظه و تعداد کوئری‌های ارسالی به دیتابیس دقت می‌کند.
4. **تعهد به ساخت ۴ پروژه:** این پروژه‌ها نمونه‌کارهای اصلی رزومه خواهند بود و تمام مباحث مصاحبه‌های فنی در آنها تعبیه شده است.

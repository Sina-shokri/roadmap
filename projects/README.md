# 🛠️ پروژه‌های عملی و رزومه‌ای نقشه راه (Hands-on Portfolio Projects)

هدف نهایی این نقشه راه، ساخت ۴ پروژه استاندارد، مدرن و گام‌به‌گام است که هر دو لاین یادگیری (Track A و Track B) را در عمل ترکیب می‌کنند. با تکمیل این پروژه‌ها، دوست شما صاحب یک **پورتفولیوی قدرتمند در گیت‌هاب** خواهد شد که آمادگی او را برای موقعیت‌های شغلی بک‌اند به کارفرمایان اثبات می‌کند.

---

## 🧭 مسیر تکامل پروژه‌ها

```
[ پروژه ۱: جاوا خالص ]
  │ ابزار CLI بنچمارک ساختمان‌داده‌ها و الگوریتم‌ها
  │ تمرکز: درک Big-O، حافظه Heap/Stack، کدهای تمیز جاوا ۲۱
  ▼
[ پروژه ۲: اولین وب‌سرویس اسپرینگ ]
  │ API مدیریت وظایف با Spring Boot 3 و PostgreSQL
  │ تمرکز: معماری لایه‌ای، DTO، کوئری‌های SQL و JPA، اعتبارسنجی
  ▼
[ پروژه ۳: محصول تجاری امن ]
  │ پلتفرم فروشگاهی با JWT Auth، کشینگ ردیس و ترنزکشن‌های بانکی
  │ تمرکز: امنیت، نقش‌ها (RBAC)، استراتژی‌های کش و تست‌نویسی با Testcontainers
  ▼
[ پروژه ۴: سیستم توزیع‌شده سطح سنیور ]
  │ معماری رخدادمحور پردازش سفارشات با Kafka و Docker
  │ تمرکز: سیستم‌های توزیع‌شده، پیام‌رسانی ناهمگام، تاب‌آوری و System Design
```

## 📌 قوانین پیاده‌سازی پروژه‌ها
1. برای هر پروژه یک مخزن مجزا در حساب گیت‌هاب دوستتان ساخته شود.
2. برای هر پروژه یک `README.md` انگلیسی با اسکرین‌شات‌ها، نحوه اجرای داکر و داکیومنت Swagger تهیه شود.
3. کدها بدون هشدار (Warning) و با رعایت اصول Clean Code و SOLID نوشته شوند.
